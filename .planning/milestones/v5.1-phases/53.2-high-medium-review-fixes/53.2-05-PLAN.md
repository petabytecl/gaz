**B7 -- gRPC server constructed in OnStart not NewServer:**
In `server/grpc/server.go`, the `NewServer` constructor currently calls `grpc.NewServer(opts...)` at line ~96. Change to:
1. Add a `serverOpts []grpc.ServerOption` field to the Server struct
2. In `NewServer`, store the opts instead of creating the server: `serverOpts: opts`
3. In `OnStart`, create the server: `s.server = grpc.NewServer(s.serverOpts...)`
4. Ensure `s.server` is nil-checked in any method that accesses it before OnStart

The pattern matches `server/vanguard/server.go` which builds httpServer in OnStart (line ~156).

Update tests that access `s.server` before OnStart to account for the deferred construction.
