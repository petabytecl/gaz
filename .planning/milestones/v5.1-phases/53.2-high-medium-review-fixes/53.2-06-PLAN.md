**Replacement strategy by category:**

**eventbus/bus_test.go (21 sites) -- async event delivery:**
Pattern: `time.Sleep(Xms)` waiting for handler to process events.
Replace with `require.Eventually(t, func() bool { return received.Load() == expected }, 2*X, X/10)` where `received` is an atomic counter. If the test uses a concrete received slice, use `len(slice) == expected` under a mutex or use atomic.

**eventbus/example_test.go (9 sites):**
Same pattern as bus_test.go. For example tests that print output, use `require.Eventually` with a condition that checks the handler was called.

**cron/internal/chain_test.go (16 sites):**
These are vendored from robfig/cron. Categorize each:
- Job completion waits: replace with channel signaling (the job writes to a `done` channel when it completes)
- Schedule tick waits: if the test needs to wait for cron to fire at a specific schedule, these may need `//nolint:timesleep` with a comment explaining why. Use this sparingly -- only when the sleep IS the test (waiting for a cron tick).

For channel signaling pattern:
```go
done := make(chan struct{})
job := cron.FuncJob(func() {
    // ... test logic ...
    close(done) // or send once
})
// ... schedule job ...
select {
case <-done:
    // job ran
case <-time.After(2 * time.Second):
    t.Fatal("job did not run within timeout")
}
```

**cron/internal/cron_test.go (10 sites):**
Same as chain_test.go. Use channel signaling where possible. For scheduler timing tests where sleep IS the mechanism, add `//nolint:timesleep -- cron scheduler requires real-time wait for schedule tick`.

**cron/internal/option_test.go (2 sites):**
Same approach -- channel signaling preferred.

**cron/wrapper_test.go (3 sites):**
Replace with `require.Eventually` or channel.

**server/vanguard/server_test.go (7 sites) -- server startup wait:**
Pattern: `time.Sleep(50ms)` waiting for server to start.
Replace with:
```go
require.Eventually(t, func() bool {
    resp, err := http.Get(fmt.Sprintf("http://localhost:%d/healthz", port))
    if err != nil {
        return false
    }
    resp.Body.Close()
    return resp.StatusCode == http.StatusOK
}, 2*time.Second, 10*time.Millisecond)
```
If the server does not have a health endpoint, use a TCP dial check:
```go
require.Eventually(t, func() bool {
    conn, err := net.DialTimeout("tcp", addr, 50*time.Millisecond)
    if err != nil {
        return false
    }
    conn.Close()
    return true
}, 2*time.Second, 10*time.Millisecond)
```

**server/http/server_test.go (6 sites):**
Same as vanguard -- TCP dial or health endpoint check.

**server/grpc/health_adapter_test.go (6 sites):**
Replace with `require.Eventually` polling the gRPC health status.

**server/grpc/server_test.go (4 sites):**
Same TCP dial pattern as above.

**General rules for ALL replacements:**
- Never use `time.Sleep` in the replacement (no `time.Sleep` -> `time.Sleep` with different duration)
- Timeout for `require.Eventually` should be 2x the original sleep duration (minimum 1s)
- Poll interval should be 1/10 of the original sleep (minimum 10ms)
- Add `"net"` import if using TCP dial pattern
- Ensure `testify/require` is imported
