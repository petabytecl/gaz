## Replacement Strategy by Pattern

### require.Eventually (most common)
Used for async delivery waits, server startup detection, health status polling:
```go
require.Eventually(t, func() bool {
    return count.Load() == expected
}, time.Second, 10*time.Millisecond)
```

### waitForPort TCP dial (server tests)
Added to vanguard, HTTP, and gRPC server test packages:
```go
func waitForPort(t *testing.T, port int) {
    require.Eventually(t, func() bool {
        conn, err := net.DialTimeout("tcp", addr, 50*time.Millisecond)
        // ...
    }, 2*time.Second, 10*time.Millisecond)
}
```

### bus.Close() (eventbus example tests)
Example functions cannot use require.Eventually (no *testing.T parameter). Replaced time.Sleep with bus.Close() which waits for all handlers to complete.

### require.Never (negative assertions)
Used where the original test verified that something did NOT happen:
```go
require.Never(t, func() bool {
    return count.Load() > 0
}, 100*time.Millisecond, 10*time.Millisecond)
```

### runtime.Gosched (contention window tests)
For tests that used sub-millisecond sleeps to increase race detection contention window.

### Channel signaling (cron chain tests)
Replaced sleep-based job completion waits with channel-based synchronization.
