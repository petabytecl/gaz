## Changes Made

### A7: ReplaceService Post-Build Guard
- Changed `ReplaceService` signature from `func(name, svc)` to `func(name, svc) error`
- Added `built` flag check returning `ErrAlreadyBuilt` -- matches existing `Register()` guard pattern
- Updated all 3 callers: `di/registration.go` (2 sites), `gaztest/builder.go` (1 site)
- Enforces CLAUDE.md Rule 4: "Container.Register() and Container.ReplaceService() MUST return an error when called after Build()"

### A8: Eager Resolve Determinism
- Added `sort.Slice(eagerServices, ...)` by Name() in `Build()` after collecting eager services
- Guarantees alphabetical resolution order regardless of map iteration order
- Test `TestEagerResolveOrder` verifies services named "c", "a", "b" resolve as "a", "b", "c"

### A9: Failed Build Locks Container
- Moved `c.built = true` outside the error-only branch in `Build()`
- Now sets `built=true` after the eager resolve loop regardless of whether `buildErr` was set
- Prevents container from entering limbo state where Build failed but new registrations are accepted
- Test `TestFailedBuildLocksContainer` verifies Register returns ErrAlreadyBuilt after failed Build

### B3/B4: Duplicate Named Detection
- Added duplicate check in `registration.go` Provider() and Instance() methods
- Detection logic: if `b.name != b.typeName` (Named() was called) AND `HasService(b.name)`, return `ErrDuplicate`
- Type-based registrations (`b.name == b.typeName`) continue to append for multi-binding support
- `Replace()` bypasses the duplicate check (by design -- it calls ReplaceService)
- ErrDuplicate now has production code paths that return it (2 sites in registration.go)

### B1: Verified Resolved
- Confirmed di/service.go Start/Stop methods use `s.built.Load()` (atomic.Bool) without mutex
- Phase 53.1 replaced sync.Mutex with sync.Once + atomic.Bool -- no code change needed

### B14: gaztest Error Instead of Panic
- Replaced `panic("gaztest: cannot use WithApp and WithModules together")` with error accumulation
- Updated gaztest `Build()` doc to reflect error return instead of panic
- Updated `WithApp` doc: app no longer required to be pre-built

## Decisions Made

1. **Named detection via name != typeName:** Rather than adding a `named bool` field to RegistrationBuilder, used the existing invariant that Named() changes `b.name` while `b.typeName` stays as the original type name. This avoids struct changes.
2. **gaztest pre-Build replacement:** Restructured the WithApp flow so replacements happen before Build, not after. This is cleaner architecturally and respects Rule 4.
3. **Cobra test simplification:** The test pattern of registering new services inside RunE was an anti-pattern. Resolving CommandArgs directly is the intended usage.
