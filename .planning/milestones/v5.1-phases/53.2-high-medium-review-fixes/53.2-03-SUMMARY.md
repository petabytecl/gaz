## Changes

### Task 1: Vanguard config defaults + TLS warning + health server posture

**A11 - WriteTimeout/AllowZeroWriteTimeout defaults:**
- `DefaultConfig()` now returns `WriteTimeout: 30 * time.Second` (was 0)
- `DefaultConfig()` now returns `AllowZeroWriteTimeout: false` (was true)
- Added `DefaultWriteTimeout` constant for clarity
- Validation still allows zero WriteTimeout with explicit opt-in

**A12 - CORS AllowCredentials default:**
- Production `DefaultCORSConfig(false)` now returns `AllowCredentials: false` (was true)
- Dev mode unchanged (already false due to wildcard origin constraint)

**A10 - TLS warning:**
- Added `TLSConfig *tls.Config` field to Config struct (json:"-" excluded from serialization)
- `OnStart` logs `WarnContext` when `!DevMode && TLSConfig == nil`

**A16 - Health management server bind address + ShowErrors:**
- Added `BindAddress string` and `ShowErrors bool` fields to health.Config
- `DefaultConfig()` returns `BindAddress: "127.0.0.1"`, `ShowErrors: false`
- `SetDefaults()` fills empty BindAddress with "127.0.0.1"
- Server Addr format changed from `:%d` to `%s:%d` using BindAddress
- `NewReadinessHandler` now accepts `showErrors bool` parameter
- All callers (health/server.go, server/vanguard/health.go) pass config.ShowErrors

**B10 - Health server timeouts:**
- Added `ReadTimeout: 10s`, `WriteTimeout: 10s`, `IdleTimeout: 60s` to management server

### Task 2: Config env-var convention + backoff doc

**A15 - Env-var convention:**
- Changed `strings.NewReplacer(".", "__")` to `strings.NewReplacer(".", "_")` in config/manager.go
- Updated WithEnvPrefix doc to show `APP_DATABASE_HOST` (was `APP_DATABASE__HOST`)
- Updated backend_test.go to use single-underscore env var names

**A14 - Backoff doc:**
- Added "ExponentialBackOff is NOT safe for concurrent use" to struct doc-comment
- Clarified that while rand source is thread-safe, backoff state is not mutex-protected
