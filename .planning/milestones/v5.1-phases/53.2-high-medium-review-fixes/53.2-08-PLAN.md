**B12 -- Logger SetDefault side-effect:**
In `logger/provider.go` (lines ~64-65):
1. Remove `slog.SetDefault(logger)` from `NewLoggerWithWriter`
2. Add a new exported function:
```go
// SetGlobal sets the given logger as the global default via slog.SetDefault.
// Called once during App.Build(), not on every logger creation.
func SetGlobal(logger *slog.Logger) {
    slog.SetDefault(logger)
}
```
3. Find the caller that creates the logger during app wiring (likely in a module or app_build.go) and add a call to `SetGlobal(logger)` there. If the caller is in another package, the function may need to be called from the module registration.

In `logger/provider.go` (line ~81):

- Add `syscall.O_NOFOLLOW` to the flags (import `"syscall"`)

```go
cleanPath := filepath.Clean(cfg.Output)
if strings.Contains(cleanPath, "..") {
```

**B15 -- gaztest TOCTOU in RequireStart/Stop:**
In `gaztest/app.go` (lines ~32-53):
- Add `startOnce sync.Once` and `stopOnce sync.Once` fields to the App struct
- Replace the lock-check-unlock-do-lock-set pattern with:
```go
func (a *App) RequireStart() *App {
    a.tb.Helper()
    a.startOnce.Do(func() {
        ctx, cancel := context.WithTimeout(context.Background(), a.timeout)
        defer cancel()
        if err := a.app.Start(ctx); err != nil {
            a.tb.Fatalf("gaztest: app didn't start: %v", err)
        }
        a.started = true
    })
    return a
}
```
- Same pattern for RequireStop with stopOnce

**B20 -- Worker supervisor OnStop after failed OnStart:**
In `worker/supervisor.go` (lines ~195-211), after OnStart returns an error, add defensive OnStop:
```go
if err := s.worker.OnStart(s.ctx); err != nil {
    s.logger.Error("worker failed to start", slog.Any("error", err))
    s.lastError = err
    // Defensive cleanup: call OnStop even if OnStart failed
    stopCtx, stopCancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer stopCancel()
    if stopErr := s.worker.OnStop(stopCtx); stopErr != nil {
        s.logger.Warn("worker OnStop after failed OnStart", slog.Any("error", stopErr))
    }
    panicked = true
    return panicked
}
```
