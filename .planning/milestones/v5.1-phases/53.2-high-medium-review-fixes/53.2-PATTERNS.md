## Pattern Assignments

### Workstream 1: Shutdown Context Propagation (A1-A5, A13)

All items in this workstream share a single pattern: add `case <-ctx.Done()` to any blocking wait in a shutdown path. The analog is the existing `select` pattern in `server/grpc/server.go:219-233`.

---

#### `app_shutdown.go` (A1: force-exit race, A6: verify, B6: doStop caching)

**Analog:** `server/grpc/server.go` lines 219-233 (select on done vs ctx.Done)

**A1 -- Force-exit race fix pattern** (modify `app_shutdown.go:44-58`):
Current code fires `callExitFunc(1)` on `<-timer.C` without re-checking `done`. Copy the double-check idiom:
```go
// Pattern: re-check done channel after timer fires (app_shutdown.go:44-58)
go func() {
    select {
    case <-done:
        timer.Stop()
        return
    case <-timer.C:
        // Re-check: shutdown may have finished between timer fire and this point
        select {
        case <-done:
            return // Clean exit won the race
        default:
            msg := fmt.Sprintf(
                "shutdown: global timeout %s exceeded, forcing exit",
                a.opts.ShutdownTimeout,
            )
            a.getLogger().Error(msg)
            _, _ = fmt.Fprintln(os.Stderr, msg)
            callExitFunc(1)
        }
    }
}()
```

**B6 -- doStop caching pattern.** Currently `doStop` re-walks the container at `app_shutdown.go:62-71`. Cache `collectNonWorkerServices()` result on the App during `startServices()` and reuse in `doStop`:
```go
// Pattern from app_build.go:108 (discoverWorkers stores result on App)
// Store during Run/Start:
a.mu.Lock()
a.cachedServices = services
a.mu.Unlock()

// Reuse in doStop:
a.mu.Lock()

a.mu.Unlock()
```

#### `cron/scheduler.go` (A2: OnStop holds mu + ignores ctx)

**Analog:** `eventbus/bus.go` lines 243-271 (snapshot under lock, block outside lock)

**Current code** (`cron/scheduler.go:93-110`):
```go
func (s *Scheduler) OnStop(ctx context.Context) error {
    s.mu.Lock()
    defer s.mu.Unlock()          // <-- holds lock across blocking wait
    if !s.running { return nil }
    s.running = false
    cronCtx := s.cron.Stop()

    return nil
}
```

**Fix pattern** (release lock before blocking, add ctx.Done select):
```go
func (s *Scheduler) OnStop(ctx context.Context) error {
    s.mu.Lock()
    if !s.running {
        s.mu.Unlock()
        return nil
    }
    s.running = false
    s.mu.Unlock() // Release lock before blocking (Rule 1)

    cronCtx := s.cron.Stop()
    select {
    case <-cronCtx.Done():
        s.logger.InfoContext(ctx, "cron scheduler stopped")
        return nil
    case <-ctx.Done():
        s.logger.WarnContext(ctx, "shutdown deadline exceeded")
        return ctx.Err()
    }
}
```

#### `app_run.go` (A13: force-exit watcher loses second SIGINT)

**Analog:** self at `app_run.go:140-160` (signal handling pattern)

**Current code** (`app_run.go:143`): `defer signal.Stop(sigCh)` runs when `waitForShutdownSignal` returns, but the watcher goroutine in `handleSignalShutdown` reads from `sigCh` after that.

**Fix pattern** -- defer signal.Stop after watcher completes:
```go
func (a *App) handleSignalShutdown(
    ctx context.Context,
    sig os.Signal,
    sigCh <-chan os.Signal,
) error {
    shutdownCtx, cancel := context.WithTimeout(context.Background(), a.opts.ShutdownTimeout)
    defer cancel()

    shutdownDone := make(chan error, 1)
    go func() {
        shutdownDone <- a.Stop(shutdownCtx)
    }()

    // Watcher goroutine for second SIGINT (force exit)
    watcherDone := make(chan struct{})
    go func() {
        defer close(watcherDone)
        select {
        case <-sigCh:
            // Second signal received -- force exit
            callExitFunc(1)
        case <-shutdownDone:
            return
        }
    }()

    err := <-shutdownDone
    <-watcherDone // ensure watcher exits before returning (defer signal.Stop runs after)
    return err
}
```
